# Edge Shop E-Commerce Dashboard (React + TypeScript)

* **Application Interface:** [Click to Test the Demo](https://mahadasim-dev.github.io/ecommerce-shop/)

### What it does
A responsive online store app with a live-updating shopping cart basket using a REST API.

### Technical Goals & Tools Used
* **State Immutability Laws:** Used array triggers to update quantities instead of creating duplicate card rows when the same item is clicked twice.
* **Array Reduction Math:** Integrated a high-performance calculator to dynamically calculate checkout receipt sub-totals in real-time.
